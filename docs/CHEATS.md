# Cheats

## Unlock everything (3DS code)

On the **SELECT MODE** screen (title screen, then START), press in order:

**L, R, D-Up, D-Down, D-Left, D-Right, START**

(the 3DS buttons; L may also be X). A jingle plays and the background changes. This is the stock
"unlock everything" result: every machine, the X Cup and the MASTER class, saved with your
settings. It works on the Old 3DS and the New 3DS. The D-pad moves the mode cursor while you type
the code; that does not matter. A wrong button starts the code over (L starts it again at once).

Why a second code: the original N64 code (L, Z, R, C-Up, C-Down, C-Left, C-Right, START) needs the
N64 L button, which no 3DS button is mapped to, and the C buttons, which an Old 3DS does not have.
The original code is still accepted where it can be entered.

Implementation: `port/3ds/patches/decomp-3ds-unlock-3ds-code.patch`.
