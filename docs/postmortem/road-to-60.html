04 · Road to 60

The road to sixty

F-Zero X runs its logic at 60 Hz and the port never lowered that. On 10-26 both consoles race at 60: the New 3DS with headroom to spare, the Old 3DS at the edge in 3D. Most of this page is how the New 3DS got there first, from 08-14 to 09-03, on a renderer that is no longer the default. Every number is labelled with its date and build.

What the Old 3DS work gave back to the New 3DS

  • The default route. The native renderer, per-eye stereo replay and end-of-frame pacing are the New 3DS default since v1.0.0 (n60, render thread off). The render-thread path below is still built in behind an explicit ini.
  • Two audio levers (audio_ctx_narrow, audio_simd) are on in the New 3DS preset too, though it never lacked audio headroom.
  • Fixes for both models: a backlight/HOME freeze, a save that could be lost on power loss (an SD rename quirk), and a log that never blocks the frame.

Where we were. Everything below is the New 3DS campaign of 08-14 → 09-03 (v0.9.0), on the libultraship-derived interpreter with a render thread on core 2. Notes marked Later say what changed afterwards.

Where the frame went: the CPU-bound verdict

New 3DS · 08-20 measurement pass (emulator), confirmed on hardware 09-01

The measurement pass of 08-20 settled the strategy. GPU drawing time was flat at 0.4 ms per frame and the loop never once waited on the PICA; CPU build time was 26 to 58 ms. Fill rate, model decimation and texture compression were struck from the plan as irrelevant to frame time (the whole race used 8 KB of texture bytes and 957 vertices per frame). The bottleneck was the software display-list interpreter and the bridge that feeds it. Every lever from then on attacked CPU time, and every profile was reported as a set of named buckets:

BucketWhat it is
brthe bridge pre-pass: converting the game's raw display list into the runtime's command form, resolving addresses
dspinterpreter dispatch: walking the converted list and executing every command
vtxvertex transform: projecting N64 vertices to clip space on the CPU
triper-triangle work: tile extents, shader lookup, clip parameters, packed VBO emission
imptexture import: looking up or uploading textures for a draw
drwissuing the draw to citro3d, including the stereo target switch

Where this road ended

The interpreter path topped out here: a median a hair under 60 on the New 3DS, with the crowd start still the floor. For the Old 3DS it was a dead end, about 10 fps on first boot, far short of 60. That is what led to the native fork: The road to 60, all over again.
